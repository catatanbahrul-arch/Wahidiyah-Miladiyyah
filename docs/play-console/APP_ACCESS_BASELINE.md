# App Access Baseline

## Wahidiyah Miladiyyah

Status: INTERNAL REVIEW

### Current application model

Aplikasi dirancang agar fungsi informasi utama dapat digunakan tanpa akun pengguna.

Jika release aktual tidak membutuhkan login:

- Tidak perlu menyediakan akun reviewer untuk fungsi tersebut.

Jika pada release mendatang terdapat:

- login
- akun pengguna
- subscription
- area privat
- authentication
- fitur yang terkunci

maka instruksi akses reviewer harus disiapkan sebelum submission.

## Reviewer Notes

Reviewer harus dapat memahami cara menggunakan fungsi utama aplikasi tanpa akses khusus apabila fungsi tersebut memang bersifat publik.
