## Full Description

Wahidiyah Miladiyyah adalah aplikasi informasi dan kalender untuk membantu jama'ah mengakses kalender, kegiatan, pengingat, jadwal ibadah, media, pengumuman, dan informasi Wahidiyah dalam satu aplikasi.

Fitur yang direncanakan untuk release:

- Kalender Miladiyyah
- Kegiatan Wahidiyah
- Pengingat kegiatan
- Dana Box
- Jadwal Shalat
- Imsak
- Pengumuman
- Media
- Informasi Live YouTube pusat
