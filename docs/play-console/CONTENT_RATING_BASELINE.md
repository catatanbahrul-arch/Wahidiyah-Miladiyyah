# Content Rating Baseline

## Wahidiyah Miladiyyah

Status: INTERNAL REVIEW

Aplikasi dirancang sebagai aplikasi kalender, informasi kegiatan, pengingat, jadwal ibadah, media, pengumuman, dan informasi Wahidiyah.

Sebelum mengisi questionnaire Google Play:

- [ ] Review semua screen
- [ ] Review semua artikel/media
- [ ] Review semua link eksternal
- [ ] Review user-generated content jika ada
- [ ] Review iklan jika ada
- [ ] Review transaksi jika ada
- [ ] Review konten sensitif jika ada

Jawaban final harus berdasarkan konten release aktual.

Jangan menggunakan rating dari aplikasi lain sebagai acuan otomatis.
